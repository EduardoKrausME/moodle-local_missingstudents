# Missing students (local_missingstudents)

Missing students is an early-warning report for Moodle. It helps teachers and course managers identify students who have not accessed a course or the Moodle site recently.

## Features

- **Course inactivity:** uses the last access to the course (`{user_lastaccess}.timeaccess`).
- **Site inactivity:** uses the latest Moodle access (`{user}.lastaccess`).
- **Dashboard:** student counts, inactivity bands, risk levels, top cases and a searchable student list.
- **CSV export:** download the list of missing students for follow-up or retention activities.
- **Course integration:** adds a navigation link and an optional shortcut on course pages.
- **Separate groups:** users without `moodle/site:accessallgroups` only see students belonging to their own groups. Staff in no groups see no students.

Only enrolled users with `moodle/course:isincompletionreports` are counted as tracked students, following Moodle's completion-report conventions.

## Requirements and installation

Requires Moodle 4.1 or later (build `2022112800` or higher). Install this plugin under `local/missingstudents`.

For ZIP installation, download the **`missingstudents.zip`** asset from the [releases page](https://github.com/EduardoKrausME/moodle-local_missingstudents/releases). **Do not use GitHub's autogenerated “Source code (zip)” download**: it has a different root directory and Moodle will reject it.

After installation, open the report via course navigation or visit `/local/missingstudents/` to select a course.

## Configuration and permissions

The default inactivity threshold and the optional course-page shortcut are configured at **Site administration → Plugins → Local plugins → Missing students**. Authorized teachers can adjust the inactivity threshold and switch between course activity and Moodle-wide activity in the report.

Users need `local/missingstudents:viewreport` to open the report or export data. Teacher, editing teacher, course creator and manager archetypes receive this capability by default. In Separate groups courses, `moodle/site:accessallgroups` controls whether they can view all students or only their own groups.

The plugin only reads Moodle's existing enrolment and access records; it does not store a new copy of student data.
